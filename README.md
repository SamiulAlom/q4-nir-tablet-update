# How many reference assays after a change? Updating near-infrared tablet-content models across instruments and manufacturing scales

Analysis code and outputs for the paper above.

- `analysis_plan.md`: the pre-registered analysis plan, with deviations listed in section 10.
- `data_sources.md`: the public datasets used, with links and licences. Raw data are not included; download them from the listed sources.
- `notebooks/`: the analysis notebooks, run in order (01, 02, ...). The suffix CPU or GPU gives the runtime used.
- `outputs/`: every result file the paper's numbers and figures come from; `outputs/MANIFEST.md` lists them.

Trained model weights are not included.
